What’s New · Version 10.5

The Toxic Vault keeps getting smarter

Here are the latest improvements to game requests, staff review, payments, scheduling, and moderator security.

🎮

Game Requests

Request a catalog game for $5+ or an unlisted game for $10+. One viewer request slot is available at a time.

🛡️

Staff Review

The channel owner and verified Twitch moderators can approve, deny, schedule, and manage request availability.

🔒

Secure Payments

The StreamElements payment option appears only after staff approval, and payment confirmation happens automatically.

📅

Game Scheduling

Paid games are scheduled in Eastern Time as an 18–24 hour stream beginning Friday evening or Saturday morning.

✎

Schedule Changes

Rescheduling or clearing a game time requires a reason, which is shown to the viewer and included in Discord updates.

✓

Moderator Security

Twitch moderator access is checked automatically. Staff must reverify after leaving, and removed moderators lose access.
